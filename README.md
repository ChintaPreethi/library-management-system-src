# 📚 Library Management System

A simple Java console-based Library Management System that allows users to manage books in a library.

The application provides options to add, search, borrow, return, view, and remove books.

## ✨ Features

* 📖 Add new books
* 📚 View all books
* 🔍 Search books by title
* 📥 Borrow books
* 📤 Return books
* 🗑️ Remove books
* ✅ Check book availability
* 🚫 Prevent duplicate book IDs
* 🚫 Prevent removal of borrowed books
* 📋 Menu-driven interface

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner
* Loops
* Conditional Statements
* Switch Statement

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd library-management-system
```

### 3. Navigate to the source folder

```bash
cd src
```

### 4. Compile the Java files

```bash
javac Book.java LibraryManagementSystem.java
```

### 5. Run the application

```bash
java LibraryManagementSystem
```
